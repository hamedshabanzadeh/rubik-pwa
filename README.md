## درباره زوبیک

زوبیک یک شبیه‌ساز سه‌بعدی مکعب روبیک ۳×۳ است که مستقیماً در مرورگر اجرا می‌شود.

این پروژه با هدف ارائه یک تجربه سریع، مینیمال و در دسترس ساخته شده و به‌صورت Progressive Web App توسعه یافته است؛ بنابراین پس از بارگذاری اولیه، بخش‌های اصلی بازی می‌توانند بدون اتصال به اینترنت نیز اجرا شوند.

## Offline-first PWA

زوبیک با معماری **Offline-first** توسعه داده شده است.

پس از اولین بارگذاری، قابلیت‌های اصلی بازی بدون اتصال دائمی به اینترنت قابل استفاده هستند.

فایل‌های مورد نیاز Runtime، از جمله Three.js و Scrambler، به‌صورت Local در پروژه نگهداری شده و توسط Service Worker مدیریت و Cache می‌شوند.

اتصال اینترنت عمدتاً برای بارگذاری اولیه، دریافت نسخه‌های جدید و قابلیت‌هایی که ذاتاً به شبکه نیاز دارند استفاده می‌شود.
