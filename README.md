# نقشه راه طراحی و توسعه وب برای مبتدیان

یک نقشه راه تعاملی و فارسی برای افرادی که می‌خواهند مسیر **طراحی رابط کاربری تا توسعه واقعی وب** را از پایه شروع کنند.

## 🌐 مشاهده نسخه آنلاین

**[مشاهده نقشه راه تعاملی](https://hamedshabanzadeh.github.io/web-design-roadmap-for-beginners/)**

---

این پروژه تلاش می‌کند مسیر یادگیری را به زبان ساده و مرحله‌به‌مرحله نشان دهد؛ از ایده و وایرفریم تا Figma، HTML، CSS، JavaScript، GitHub، انتشار سایت و در نهایت استفاده اصولی از ابزارهای هوش مصنوعی.

## مسیر یادگیری

در این نقشه راه با این مسیر آشنا می‌شوید:

`ایده و نیازها ← Wireframe ← UX/UI ← Figma ← HTML ← CSS ← Responsive Design ← JavaScript ← Git/GitHub ← Deploy ← AI Tools`

## رویکرد پروژه به هوش مصنوعی

هدف این نقشه راه، جایگزین کردن یادگیری با هوش مصنوعی نیست.

> **اگر نمی‌توانید خروجی AI را بررسی، توضیح و اصلاح کنید، هنوز نباید آن کار را به‌طور کامل به AI بسپارید.**

ابتدا باید اصول طراحی و توسعه وب را یاد گرفت و حداقل یک پروژه را از ابتدا تا انتها ساخت.

بعد از آن، ابزارهای هوش مصنوعی می‌توانند به‌عنوان یک **دستیار، منتقد، معلم و شتاب‌دهنده** وارد فرایند کار شوند.

مسیر پیشنهادی:

`یادگیری اصول ← ساخت پروژه واقعی ← درک کد و طراحی ← استفاده از AI ← سرعت و بهره‌وری بیشتر`
