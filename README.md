# زوبیک (Zubik)

زوبیک یک بازی مکعب روبیک ۳×۳ سه‌بعدی، روان و آفلاین است که برای موبایل و دسکتاپ طراحی شده است.

 **اجرای آنلاین زوبیک:**  
https://hamedshabanzadeh.github.io/zubik/

## ویژگی‌ها

- مکعب روبیک سه‌بعدی ۳×۳
- کنترل با لمس و ماوس
- Scramble خودکار
- تایمر با دقت صدم ثانیه
- شمارش تعداد حرکت
- تشخیص حل مکعب
- ثبت بهترین رکورد
- اشتراک‌گذاری نتیجه
- اجرای کامل آفلاین پس از نصب
- قابل نصب به‌صورت PWA / Add to Home Screen
- به‌روزرسانی دستی از داخل برنامه
- رابط کاربری فارسی و RTL
- سازگار با موبایل و دسکتاپ

## نصب روی موبایل

زوبیک یک PWA است و بدون نیاز به App Store یا Google Play می‌تواند روی گوشی نصب شود.

1. لینک زوبیک را در مرورگر باز کنید.
2. گزینه **Add to Home Screen** را انتخاب کنید.
3. بعد از نصب، زوبیک مانند یک اپ مستقل اجرا می‌شود.
4. پس از اولین بارگذاری، بخش اصلی بازی بدون اینترنت نیز در دسترس است.

## معماری آفلاین

زوبیک با معماری Offline-first طراحی شده است.

پس از اولین بارگذاری، فایل‌های اصلی بازی توسط Service Worker در Cache ذخیره می‌شوند و بازی می‌تواند بدون اتصال اینترنت اجرا شود.

اینترنت فقط برای موارد زیر لازم است:

- اولین بارگذاری و نصب
- دریافت نسخه‌های جدید
- قابلیت‌هایی که ذاتاً به اینترنت نیاز دارند
